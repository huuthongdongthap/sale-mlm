## 5. LTV MODEL — TẦM QUAN TRỌNG DÀI HẠN

### Customer Lifetime Value (LTV) theo funnel stage

```
Stage Funnel:  Stranger → Lead → Coach → L1 Buyer → L2 Buyer → L3 Buyer → Partner (CTV)

LTV Calculation:
  L1 only:          590.000đ  × 30% repeat = 177.000đ
  L1 + L2:          590.000 + 4.000.000 = 4.590.000đ × 15% = 688.500đ
  L1 + L2 + L3:     590.000 + 4.000.000 + 12.500.000 = 17.090.000đ × 5% = 854.500đ
  CTV partner:      0đ trực tiếp, nhưng recruitment value = 3.000.000đ bonus × 1 referral = 3M

  Weighted LTV:     854.500 + (5% × 3.000.000) = 1.004.500đ ≈ **~1tr VND/customer**
```

### LTV:CAC Ratio

```
CAC (Phase 1, organic): ~375.000đ / 4 đơn
LTV: ~1.000.000đ
LTV:CAC = 1.000.000 / 375.000 = **2.7:1** ✅ (good: >3 is great, >1 is viable)
```

Nếu tính COGS cho L2/L3:
```
Net LTV = 1.000.000 - 500.000 (COGS L2/L3 proportion) = ~500.000đ
LTV:CAC net = 500.000 / 375.000 = 1.3:1 ✅ (still viable)
```

## 9. UNIT ECONOMICS — CHI TIẾT TỪNG ĐƠN

### L1 Order Economics (590k VND)

```
Revenue:               590.000đ
  - COGS (product):   -177.000đ (30%)
  - Shipping:         -30.000đ
  - Payment fee:      -5.900đ (1%)
  = Gross Profit:     377.100đ (64%)

  - Claude API cost:  -7.000đ (1 session × ~4k tokens Haiku)

  = Net Profit:       369.600đ (62.6%)

CAC: 1.500.000đ / 4 đơn = 375.000đ
Payback: 375.000 / 369.600 = **1.01 order** → break-even ngay đơn đầu tiên net
```

```
CAC:                   375.000đ
```
